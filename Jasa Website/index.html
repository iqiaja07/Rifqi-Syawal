05 — FAQ

Pertanyaan yang
sering ditanyakan.

Berapa lama pembuatan website?

Waktu pengerjaan mengikuti jumlah halaman, kompleksitas fitur, kesiapan materi, dan proses revisi. Estimasi final dibahas sebelum project dimulai.

Apakah bisa menggunakan domain sendiri?

Bisa. Jika kamu sudah memiliki domain, domain tersebut dapat diarahkan ke hosting. Jika belum, RFWS dapat membantu proses setup domain sesuai kesepakatan.

Apakah website bisa dibuka di HP?

Ya. Website dirancang responsive agar layout menyesuaikan desktop, tablet, dan smartphone.

Apakah bisa request desain seperti referensi?

Bisa. Kamu dapat mengirim referensi visual. Desain kemudian disesuaikan dengan kebutuhan dan identitas project.

Bagaimana sistem pembayaran?

Skema pembayaran, DP, termin, dan pelunasan ditentukan di awal dan dicantumkan dalam kesepakatan/invoice project.
