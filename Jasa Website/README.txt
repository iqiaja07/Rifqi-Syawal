# RFWS — Website Jasa Pembuatan Website

File:
- index.html  → halaman utama
- styles.css  → seluruh UI/UX dan responsive design
- script.js   → interaksi, tahun otomatis, dan form WhatsApp

## Cara menjalankan
1. Letakkan folder `rfws_website` di `htdocs` jika menggunakan XAMPP.
2. Jalankan Apache.
3. Buka `http://localhost/rfws_website/`

## WAJIB diubah
Buka `script.js`, lalu ganti:
const WHATSAPP_NUMBER = "6281234567890";
dengan nomor WhatsApp bisnis kamu (tanpa + dan tanpa spasi).

## Domain
Brand website menggunakan RFWS dan contoh domain `rfws.com`.
Domain belum dianggap terhubung hanya karena ditulis di tampilan. Untuk online, domain perlu dibeli/dikelola dan diarahkan ke hosting.
